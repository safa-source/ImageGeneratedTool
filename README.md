# ImageGeneratedTool

ImageGeneratedTool is a PHP-based web application developed to demonstrate user authentication and database management. Built using **HTML, CSS, Bootstrap, JavaScript, PHP, and MySQL**, the project focuses on implementing a secure registration and login system.

Users must first register an account and then log in using their valid credentials to gain access to the website's home page. Unauthorized users cannot access the home page without successfully authenticating.

### Key Features
- User Registration and Account Creation
- Secure Login Authentication
- MySQL Database Integration
- Credential Validation
- Restricted Access to the Home Page
- Bootstrap-Based Responsive User Interface
- PHP Backend Functionality

### Technologies Used
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** PHP
- **Database:** MySQL

### Project Purpose
The primary purpose of this project is to demonstrate the implementation of a basic user authentication system, including registration, login validation, database connectivity, and access control in a web application.
